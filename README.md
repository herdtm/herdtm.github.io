# herdtm.github.io

Liefert nur den öffentlichen Schlüssel für die Tesla-Fleet-Anbindung von Home Assistant aus:
`/.well-known/appspecific/com.tesla.3p.public-key.pem`

`.nojekyll` sorgt dafür, dass GitHub Pages den Punkt-Ordner `.well-known` nicht weglässt.
Der private Schlüssel liegt ausschließlich in Home Assistant.
